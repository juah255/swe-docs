# Projects

Project-specific documentation and delivery notes.

## Mid/Senior Interview Questions and Answers

### 1. What project details matter in a senior engineering interview?

**Answer:** Focus on architecture, ownership, constraints, trade-offs, failures,
debugging stories, scaling decisions, security, observability, and measurable
impact.

Avoid only listing features. Senior interviews look for judgment and evidence
that you can operate systems after building them.

### 2. How should a project architecture be explained?

**Answer:** Start with the user problem, then explain main components, data
model, request flow, integrations, deployment model, and key trade-offs.

Include why alternatives were rejected. That shows design reasoning, not just
implementation recall.

### 3. How do you discuss project failures?

**Answer:** Explain the symptom, impact, investigation, root cause, fix, and
prevention. Be specific about what changed afterward.

Strong answers show ownership without blaming people.
