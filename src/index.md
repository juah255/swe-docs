## Mid/Senior Interview Questions and Answers

### 1. How should these docs be used for interview preparation?

**Answer:** Use each topic page to connect definitions with production
trade-offs, failure modes, and concrete examples from real projects.

Mid/senior interviews rarely stop at "what is it?" Follow up with when to use
it, when not to use it, and how it fails.

### 2. What makes an answer senior-level?

**Answer:** A senior-level answer explains constraints, alternatives,
trade-offs, operational impact, and how the decision would be validated.

It should include enough detail to show ownership of production behavior, not
just familiarity with terminology.
