# Incident Response

## Incident Response

Typical response flow:

1. Detect suspicious behavior.
2. Triage severity and scope.
3. Contain the issue.
4. Preserve evidence.
5. Eradicate the root cause.
6. Recover service safely.
7. Rotate exposed secrets if needed.
8. Review the incident and improve controls.

Prepare before an incident happens. Maintain runbooks and playbooks for common
scenarios, and know who is on call and how to escalate. Define severity levels
and clear roles so decisions during an incident are fast and unambitious.

See [Security Monitoring](security-monitoring.md) for detection, [Logging](logging.md)
for the evidence trail, and [Forensics Basics](forensics-basics.md) for
preserving evidence during response.
