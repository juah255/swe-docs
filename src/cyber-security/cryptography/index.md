# Cryptography

Cryptography protects confidentiality, integrity, authenticity, and password
verification when used correctly. It underpins HTTPS, signatures, certificates,
and secrets handling across applications and infrastructure.

Practical cryptography means using well-established algorithms and libraries
correctly, protecting keys, and understanding what each primitive can and
cannot guarantee.
