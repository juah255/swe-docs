# Infrastructure Security

Infrastructure security protects the networks, hosts, and platforms that
software runs on. It covers access paths, boundaries, runtime behavior, and
operating system configuration.

Controls here complement application-level security. Even well-written code can
be undermined by exposed networks, misconfigured clouds, or hardened-by-default
hosts being absent.

## Topics

- [Network Security](network-security.md): TLS, inbound and outbound controls.
- [Firewalls](firewalls.md): stateful filtering, WAFs, and deny-by-default
  rules.
- [VPN](vpn.md): controlled remote access and site-to-site connectivity.
- [DNS Security](dns-security.md): DNS risks, DNSSEC, and hardening resolvers.
- [Cloud Security](cloud-security.md): shared responsibility, IAM, and storage.
- [Container Security](container-security.md): images, runtime, and scanning.
- [Kubernetes Security](kubernetes-security.md): RBAC, network policies, and
  secrets.
- [OS Hardening](os-hardening.md): patching, least privilege, and audit
  logging.
