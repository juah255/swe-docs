# Kubernetes Security

Kubernetes clusters run many workloads, so access and policy controls matter.

Important controls:

- Role-based access control (`RBAC`).
- Network policies.
- Pod security controls.
- Secrets management.
- Image admission policies.
- Resource limits.
- Audit logs.

Cluster access should be treated as production infrastructure access.
