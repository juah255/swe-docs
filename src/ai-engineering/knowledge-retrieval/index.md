# Knowledge Retrieval

Knowledge retrieval covers the pipelines that find relevant content for a model
before generation: chunking, embeddings, vector storage, hybrid search,
re-ranking, and context compression. Retrieval quality determines answer
quality, so each stage deserves explicit design and evaluation.
