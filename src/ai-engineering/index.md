# AI Engineering

AI engineering focuses on building reliable software systems around models.
The model is one dependency in a larger product system that also includes data,
retrieval, prompts, tools, evaluation, monitoring, deployment, cost control, and
safety.

## Learning Path

Follow these topics in order when learning AI engineering from the beginning:

1. [Foundations](foundations/index.md): what AI engineering is, LLM
   fundamentals, tokens and context windows, embeddings, prompt engineering,
   and structured outputs.
2. [Model Integration](model-integration/index.md): AI APIs, streaming, chat
   completions, function/tool calling, and vision, image, audio, and reasoning
   models.
3. [Knowledge Retrieval](knowledge-retrieval/index.md): RAG, chunking,
   embedding models, vector databases, hybrid search, re-ranking, and context
   compression.
4. [AI Agents](ai-agents/index.md): agent fundamentals, planning, memory,
   multi-agent systems, workflows, MCP, and tool ecosystems.
5. [Frameworks](frameworks/index.md): LangChain, LangGraph, LlamaIndex, OpenAI
   SDK, Vercel AI SDK, Pydantic AI, and Mastra.
6. [Evaluation](evaluation/index.md): prompt, RAG, and agent evaluation,
   benchmarks, human evaluation, and automated evaluation.
7. [Production](production/index.md): observability, cost and latency
   optimization, caching, guardrails, safety and security, deployment, and
   MLOps/LLMOps.

## Suggested Practice

- Build a document Q&A system with RAG and source citations.
- Add structured JSON extraction from messy text and validate the schema.
- Create a support-ticket classifier with evaluation data.
- Build a tool-calling assistant that can query a read-only API.
- Add tracing, token usage, cost tracking, and feedback collection.
- Compare two prompts or two models using the same evaluation dataset.
- Add prompt-injection test cases to a RAG pipeline.
