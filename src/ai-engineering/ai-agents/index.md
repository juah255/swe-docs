# AI Agents

AI agents use models to choose steps, call tools, and act on intermediate
results, in contrast to fixed workflows. This section covers agent
fundamentals, planning, memory, multi-agent systems, workflows, the Model
Context Protocol, and the tool ecosystems agents operate in.
